# Candidate start here

1. Read the separate TOX INTL assignment document in full.
2. Create a new branch from `main` using your name.
3. Start the stack using the root `README.md`.
4. Reproduce and map the reported behaviour before making functional changes.
5. Keep your required investigation notes and deliverables in the repository.
6. Do not squash your commits before submission.

The starter code intentionally has incomplete behaviour. A green baseline test run does not prove that the reported behaviours are correct.
